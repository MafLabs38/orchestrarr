# Review decisions: pull request 82 (the screens follow the fab: Flow, Queue, History, decisions taken)

## R-82-1 | architecture | major | fixed

- **Finding**: A decision done was judged against the time Orchestrarr read Portarr, not the time Portarr observed the fleet, so an older observation could offer it again.
- **Where**: `ProblemsEndpoints.MarkWorkedOn`, `PortarrFleetMapper`
- **Reason**: fixed: Portarr's `codeSource.scannedAt` is carried as `FleetSnapshot.ObservedAt` and the table judges against it; tested.

## R-82-2 | quality | major | fixed

- **Finding**: The hold and the priority in the line acted first and recorded second, then undid, unlike the release and the priority in process.
- **Where**: `FlowEndpoints`
- **Reason**: fixed: every act of a person is written before it is made; a hold that finds the operation gone says so in the trail.

## R-82-3 | quality | major | fixed

- **Finding**: A priority set in the line reached the started problem by a second call whose result was dropped, under a pseudo-actor name.
- **Where**: `ProblemStarter.StartQueuedAsync`
- **Reason**: fixed: the priority is given to the start itself (`ProblemConductor.StartAsync`), with no second call.

## R-82-4 | security | low | fixed

- **Where**: `FlowEndpoints`
- **Reason**: fixed with R-82-2.
