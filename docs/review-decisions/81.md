# Review decisions: pull request 81 (the flow is a fab: lots, routes, bots' pull requests, fix forward)

## R-81-1 | architecture | blocker | fixed

- **Finding**: The pipelines left the floor while FR-WLD-7, FR-SAF-1, FR-LAB-7, FR-WLD-10, CASE-08, D-98 and the README still said an agent never touches a pipeline.
- **Where**: docs, `MissionModel.cs`
- **Reason**: fixed: the documents now say what the code does (the pipelines are in the frame of every operation that is not about them, never weakened, ADR 0055 point 7); the floor of the certificate keeps CODEOWNERS, the bot's configuration, submodules and secrets. For deployments too, the restriction of each operation is now signed in its certificate (R-81-96), so it is held by the verifier, not only by the conductor.
