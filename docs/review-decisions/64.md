- **Finding**: A new write power (branches, commits of an agent, pull requests, closing a pull request) without a recorded decision.
- **Where**: ADR 0044, `CLAUDE.md`
- **Reason**: fixed as far as a document can: ADR 0044 records that the maintainer agreed the plan of the first real pass, whose third step is this one, in the chat of 2026-11-21, and says that the choices of the ADR are his to confirm in this pull request. The merge of this pull request is his (rule 15).

## R-64-2 | security | high | fixed

- **Finding**: The same: the gateway writes new content to a repository, which ADR 0043 did not cover.
- **Where**: ADR 0044
- **Reason**: fixed with the previous entry; the powers are bounded to the development test bed, to the named repositories, to the gateway's own token, and written in the audit trail.

## R-64-3 | security | high | fixed

- **Finding**: The pipeline of a repair that is not in a pull request was read as green for every query of the problem, so a merge could fall back on the original pull request, which is red.
- **Where**: `SandboxFacts`, `MissionActEndpoints`
- **Reason**: fixed: the declaration holds only at the crossing into the Git world (no repository named), and a repair that was made is never merged or deployed around; tested.

## R-64-4 | architecture | major | fixed

- **Finding**: The pending repair and the replacement pull request live in memory only, and losing them fell back on the original pull request.
- **Where**: `RepairRegistry`, `MissionActEndpoints`
- **Reason**: fixed: the staging dossier carries `repair:files=N`, and while no pull request holds a repair that was made the merge and the deployment are refused and the opening says that the repair is lost, so the problem goes back; tested with a restart.

## R-64-5 | architecture | major | fixed

- **Finding**: The denylist of the repair misses the tests, pipelines and settings of other ecosystems.
- **Where**: `RepairPolicy`
- **Reason**: fixed: Go, .NET, Java, Ruby tests, other forges' pipelines, runtime and package-manager settings, and the forbidden-paths floor of the conductor are in; the list is said to be a floor, bounded further by the limits and the pipeline of the repository; tested.

## R-64-6 | security | medium | fixed

- **Finding**: The files were read back after the build of the change under test had run, which could rewrite them.
- **Where**: `RepairAgent`
- **Reason**: fixed: they are read, and the tree is made, before anything runs again.

## R-64-7 | security | medium | fixed
