- **Reason**: declined: an install needs the network and a fork's code is untrusted; the staging machine is restored after each job and holds no secret, and what the code sends out is for the lab network to contain, which is the staging platform vertical. Written in ADR 0042 6(f) and 6(c).

Written in ADR 0042 6(d).
